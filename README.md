# 🎧 TechWave - Podcast Website

A fully responsive podcast website built as part of an assignment project using **HTML5** and **CSS3 / Tailwind CSS**.

---

## 🌟 About The Project

TechWave is a modern podcast website designed based on a Figma layout.  
It focuses on clean UI, responsive design, and smooth user experience across all devices.

---

## 🚀 Features

- Fully responsive design (mobile, tablet, desktop)
- Modern UI based on Figma design
- Navigation bar with mobile hamburger menu
- Hero banner with podcast visual layout
- About section with statistics
- Feature cards section
- Featured podcast episodes with embedded YouTube videos
- Host section with profile and social links
- Clean footer section

---

## 🛠️ Tech Stack

- HTML5
- CSS3 / Tailwind CSS
- Responsive Design (Flexbox & Grid)

---

## 📱 Responsive Design

- 📱 Mobile: ≤ 576px  
- 💻 Tablet: 576px – 992px  
- 🖥️ Desktop: ≥ 992px  

---

## 🙌 What I Learned

- Converting Figma designs into real UI
- Responsive layout techniques
- Tailwind CSS utility classes
- Clean component-based HTML structure
